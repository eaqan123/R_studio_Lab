Project Overview

This repository contains beginner-level R programming exercises focused on data analysis, statistics, and visualization.

As a BS Artificial Intelligence student, I am using this repository to practice data analysis concepts and develop my programming skills.

Project 1: Student Performance Analysis

This project analyzes the exam marks of five students using R programming.

Features

* Stores student names and marks.
* Calculates average, highest, and lowest marks.
* Classifies students as Pass or Fail.
* Creates a bar chart to visualize student performance.

Results

* Average Marks: 75.4
* Highest Marks: 92
* Lowest Marks: 55
* Passing Students: 5 out of 5

Technologies Used

* R Programming
* Base R functions

How to Run

1. Install R or RStudio on your computer.
2. Download Student_performance.R from this repository.
3. Open the file in RStudio.
4. Run the code to view the results and bar chart.
